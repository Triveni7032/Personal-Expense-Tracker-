# Personal Expense Tracker

## About the Project

Personal Expense Tracker is a beginner-friendly Python
console application used to record and manage personal
expenses.

The application allows users to add, view, delete, and
summarize expenses by category.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- View unique expense categories
- View spending by category
- Delete expenses
- Simple menu-driven interface

## Python Concepts Used

- Functions
- Lists
- Tuples
- Sets
- Dictionaries
- Loops
- Conditional Statements
- User Input
- Type Conversion

## Data Structures Used

### List

Used to store multiple expense records.

### Dictionary

Used to store individual expense details such as
name, amount, and category.

### Set

Used to store unique expense categories.

### Tuple

Used to store fixed expense status information.
